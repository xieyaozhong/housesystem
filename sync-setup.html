CLOUD SYNC

跨裝置同步設定

家總管會使用 Firebase Authentication + Cloud Firestore。退租資料上傳前會再用管理密碼在瀏覽器端 AES-GCM 加密，因此 Firestore 儲存的是密文。

1. Firebase Web App 設定

Firebase Web 設定本身不是管理密碼，但仍需搭配 Authentication 與 Firestore Rules。每台新裝置只需設定一次。

2. 管理員登入

讀取狀態中…

3. Firestore 權限

① Firebase Console 開啟 Email/Password Authentication
② 建立 Cloud Firestore
③ 將 repo 內的 firestore.rules 規則部署到 Firestore Rules
④ 登入後，這裡會顯示 UID；在 Firestore 手動建立 housesystem_members/{UID} 文件（內容可只放 role: "admin"）
⑤ 其他管理員各自建立 Auth 帳號並加入自己的 UID 白名單

不要把 Firebase 登入密碼、管理密碼或 Service Account 金鑰提交到 GitHub。
